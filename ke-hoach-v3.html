🗺️ Kế hoạch triển khai — CleanBoost v3.0

Ngày lập: 19/10/2026 • Dựa trên file đề xuất de-xuat-tinh-nang-moi.html

Tài liệu này mô tả kiến trúc module, cách làm từng tính năng, thứ tự triển khai và cách test.

1. Kiến trúc module mới

Giữ nguyên triết lý hiện tại: core/ = thao tác hệ thống, cleaner/ = dọn dẹp, safety/ = bảo vệ, ui/ = giao diện. Thêm package network/ cho mọi thứ liên quan mạng:

cleanboost/
├── network/                  ← PACKAGE MỚI (tab "Mạng")
│   ├── __init__.py
│   ├── info.py               → A.8  Network Info Dashboard (IP local/global, gateway, DNS, MAC, WiFi)
│   ├── ports.py              → A.9  Port & SSH Inspector (cổng LISTEN, cảnh báo cổng nguy hiểm)
│   ├── diag.py               → A.10 Network Diagnostics (ping, kết luận tự động)
│   ├── refresh.py            → A.1  Quick Refresh (flushdns/release/renew)
│   │                         → A.2  Adapter Reset (Disable/Enable-NetAdapter)
│   │                         → A.4  Deep Reset (winsock/int ip reset)
│   ├── dns.py                → A.3  DNS Switcher + đo tốc độ DNS
│   ├── speed.py              → A.5  Speed Test trước/sau
│   ├── hogs.py               → A.6  Bandwidth Hog Finder
│   └── guard.py              → A.7  Auto Internet Guard (thread nền)
├── core/
│   ├── health.py             → B.2  Health Score 0–100           (MỚI)
│   ├── startup.py            → B.3  Startup Manager              (MỚI)
│   ├── profiles.py           → B.5  Profile Game/Làm việc        (MỚI)
│   └── history_db.py         → B.7  Lưu mẫu RAM/CPU/mạng 30s/lần (SQLite) (MỚI)
├── cleaner/
│   └── duplicates.py         → B.4  Duplicate Finder (hash SHA-256) (MỚI)
├── ui/app.py                 → thêm tab "Mạng", nút ⚡ Optimize, Health Score, tray icon
└── safety/protected.py       → thêm DANH SÁCH CỔNG NHẠY CẢM (23, 3389, 445, 5900...)
Quy ước an toàn (bắt buộc mọi module mới tuân theo): hàm nào cũng trả về (ok, message), không bao giờ raise ra ngoài; thao tác cần admin → kiểm tra privilege.is_admin() trước và báo rõ; thao tác nguy hiểm → cảnh báo + checkbox xác nhận riêng; mọi hành động ghi vào action_log như các tính năng cũ.

2. Cách làm chi tiết từng tính năng

A.8 — Network Info Dashboard P0

Cách làm: toàn bộ chỉ đọc, không cần admin, chạy 1 lần khi mở tab (có nút Refresh).

Thông sốCách lấy (Windows)Fallback
Local IP / Subnet / MACpsutil.net_if_addrs() — lọc card đang UPsocket.gethostbyname()
Global IPHTTP GET https://api.ipify.org (timeout 5s)https://ifconfig.me, lỗi → "không lấy được"
Gatewayparse ipconfig hoặc route print—
DNS đang dùngnetsh interface ip show dns / parse ipconfig—
WiFi: SSID, sóng %, tốc độnetsh wlan show interfaces → parse Signal/Receive rateẩn mục nếu dùng LAN

Test: chạy trên máy thật, đối chiếu với ipconfig /all — mọi số phải khớp.

A.9 — Port & SSH Inspector P0

Cách làm:

# 1. Liệt kê cổng đang nghe
conns = psutil.net_connections(kind='inet')
listen = [c for c in conns if c.status == 'LISTEN']
# → với mỗi cổng: laddr.port, laddr.ip (0.0.0.0 = mở ra cả LAN!), pid → tên process

# 2. Kiểm tra SSH riêng
ssh_open = any(c.laddr.port == 22 for c in listen)

# 3. Cảnh báo: cổng trong DANH SÁCH NHẠY CẢM mà bind 0.0.0.0 → cờ đỏ
SENSITIVE_PORTS = {23:'Telnet', 3389:'Remote Desktop', 445:'SMB',
                   5900:'VNC', 21:'FTP', 3306:'MySQL', 5432:'PostgreSQL'}

UI: bảng 4 cột — Cổng | Process | Phạm vi (LAN/Chỉ máy này) | Mức độ (xanh/vàng/đỏ). Nút "Hướng dẫn đóng" mở popup giải thích từng cổng.

Test: bật/tắt OpenSSH Server trên Windows để kiểm tra báo đúng port 22 mở/đóng.

A.1 + A.2 + A.4 — Quick Refresh / Adapter Reset / Deep Reset P0 P1

Cách làm: mỗi thao tác là 1 hàm trong network/refresh.py, chạy tuần tự trong thread nền, UI hiện progress từng bước (tái dùng busy-guard đã có từ v2.3).

def quick_refresh():            # không cần admin
    run("ipconfig", "/flushdns")     # bước 1/3
    run("ipconfig", "/release")      # bước 2/3
    run("ipconfig", "/renew")        # bước 3/3

def adapter_reset(name="Wi-Fi"):     # CẦN ADMIN + đếm ngược 3s + nút Hủy
    powershell Disable-NetAdapter → sleep 3 → Enable-NetAdapter

def deep_reset():                    # CẦN ADMIN + cảnh báo đỏ "cần restart máy"
    run("netsh", "winsock", "reset")
    run("netsh", "int", "ip", "reset")

Test: đo ping trước/sau trên máy thật; Adapter Reset phải tự kết nối lại WiFi trong 30s.

A.3 — DNS Switcher P1

Cách làm: luôn lưu DNS cũ vào file config trước khi đổi → nút "Hoàn tác" khôi phục chính xác. Đo tốc độ DNS bằng cách resolve google.com 5 lần qua từng DNS (dùng nslookup với server chỉ định) rồi gợi ý cái nhanh nhất.

# Đổi (cần admin):
netsh interface ip set dns "Wi-Fi" static 1.1.1.1
netsh interface ip add dns "Wi-Fi" 1.0.0.1 index=2
# Hoàn tác: đọc DNS đã lưu → set lại như cũ

A.5 — Speed Test P0 & A.10 — Diagnostics P1

Cách làm (không thêm thư viện ngoài): ping bằng subprocess ping -n 4 parse thời gian trung bình; tốc độ tải bằng download file test 10MB từ CDN (đo bytes/giây); DNS resolve time bằng nslookup. Diagnostics chạy 4 bài kiểm tra rồi áp luật loại trừ để kết luận:

ping gateway cao   → "WiFi/LAN có vấn đề — lại gần router / kiểm tra dây"
ping gateway ổn + ping 1.1.1.1 cao → "Do nhà mạng/tuyến quốc tế — thử Quick Refresh"
dns resolve chậm   → "Nên đổi DNS (sang mục DNS Switcher)"
tất cả ổn          → "Mạng bình thường — lag có thể do app/server game"

A.6 — Bandwidth Hog Finder P1 & A.7 — Auto Guard P2

Hog Finder: chụp psutil.net_io_counters(pernic=True) 2 lần cách nhau 3s → chênh lệch = tốc độ hiện tại; map connection → process qua psutil.net_connections(). Tái dùng bảng process + nút End task của tab Processes.

Auto Guard: thread daemon ping 1.1.1.1 mỗi 5 phút; 3 lần liên tiếp > 300ms → toast "Mạng có vẻ chậm — bấm để Quick Refresh". Không tự chạy refresh khi chưa được bấm. Có toggle bật/tắt trong Settings.

B.1 — Nút ⚡ Tối ưu 1 chạm P0 & B.2 — Health Score P0

Optimize: 1 hàm run_optimize() gọi tuần tự: memory_cleaner.light_clean() → quét+dọn mức 1 (nhóm default_on) → network.refresh.quick_refresh() → trả về báo cáo dict. Progress bar tổng 0–100%.

Health Score (core/health.py) — công thức minh bạch, hiện ngay dưới điểm số:

score = 100
  - (100 - %RAM trống) × 0.3        # RAM
  - (100 - %đĩa trống) × 0.3        # đĩa
  - min(rác quét được / 5GB, 1) × 20 # rác
  - min(số app startup / 20, 1) × 10 # startup
  - (ngày từ lần dọn cuối / 30) × 10 # độ "cũ"

B.3 → B.8 (v2.5 / v3.0)

  • Startup Manager (core/startup.py): đọc HKCU\...\Run + HKLM\...\Run (+ thư mục Startup); tắt = đổi tên value thêm tiền tố CleanBoost_disabled_ → bật lại 1 click, không mất dữ liệu.
  • Duplicate Finder (cleaner/duplicates.py): đi 2 vòng — vòng 1 nhóm theo size (rẻ), vòng 2 hash SHA-256 chỉ nhóm trùng size; UI nhóm theo hash, luôn giữ 1 bản, xóa các bản còn lại vào quarantine.
  • Profiles (core/profiles.py): lưu JSON {kill:[pid/name], after:"restore"}; nút "Khôi phục" mở lại app bằng đường dẫn exe đã lưu.
  • Dọn có điều kiện: mở rộng cleaner/scheduler.py thêm checker chạy mỗi 10 phút (RAM>92% 5 phút → light clean; đĩa <10% → dọn mức 1).
  • Lịch sử: core/history_db.py SQLite, 1 dòng/30s (timestamp, ram%, cpu%, ping) — giữ 7 ngày, tự xóa cũ.
  • Tray + toast: pystray + win10toast (thêm vào requirements, chỉ cài trên Windows).
