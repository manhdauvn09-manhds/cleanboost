04 · Vấn đề UX — "feels broken" dù code chạy

User báo "một số tính năng không chạy hoặc không như kỳ vọng" — đa số nằm ở nhóm này: code path OK nhưng cảm giác dùng đồng nghĩa hỏng.

Auto-refresh Top-10 queue chồng UX
ui/app.py:1296-1304

Mỗi ~20s Top10 auto-refresh. Nếu task trước vẫn chạy, nút disable + status "Queued: …" kéo dài. User đọc là "nút chết".

Fix: Nếu nút đang disable → bỏ round này thay vì queue. Coalesce.
Dead branches "Busy — please try again" DEAD CODE
app.py:2487,2531,2548

_run_bg luôn return True (queue-now design), nên nhánh if not started: ... không bao giờ kích. Reader tưởng có fallback.

Fix: Xoá các nhánh dead này để code nhất quán với thực tế.
report_callback_exception có lỗ hổng SAFE NET
ui/app.py:975-1002

Safety net import from gui import _crash_log_path trong handler. Nếu gui.py fail import trước đó, from gui import raise ImportError, bị swallow bởi except: pass → popup fail yên lặng.

Fix: Implement _crash_log_path tại chỗ, không phụ thuộc import chéo.
Scan level 3 treo nhiều phút UX
cleaner/scanner.py:36-95

Fix: Stream path ra disk, chỉ collect khi user tick. Cap memory. Hiện deterministic count thay vì progress indeterminate.

07 · Sửa tab Network

Tab Network hiện có 5 sub-tab phẳng và DNS label bug. Đề xuất:

  • Bỏ sub-tab phẳng → dùng accordion sections (Overview → Speed → Diagnostics → Hogs → DNS/Refresh → Repair), mở bằng mặc định cái active.
  • "DNS & Refresh" đổi tên rõ hơn: "Quick Refresh" → "Refresh DNS + IP (drop ~5s)", "Flush Network" → "Clear stale caches (no disconnect)".
  • "Current DNS" label load ngay khi vào tab Network lần đầu (apply fix bug #5).
  • Trên Linux: Disable buttons DNS/Repair/Startup thay vì để click được rồi báo "requires Windows".
  • Speed test: hiện kết quả dạng card so sánh Before/After side-by-side, không phải 2 dòng label text.
  • Bandwidth hogs: thêm cột "Avg RX/TX (3s sample)" để user thấy rõ app nào "hút băng thông".
